PUBLIC SERVICE GROUP WEBSITE
=============================

Files:
- index.html  -> मुख्य वेबसाइट
- style.css   -> डिजाइन
- script.js   -> मोबाइल menu और contact form

GitHub Pages:
1. GitHub में नया Public repository बनाएं.
2. इन तीनों files को upload करें.
3. Settings > Pages > Deploy from a branch.
4. Branch: main, Folder: / (root), Save.
5. कुछ समय बाद Visit site से वेबसाइट खोलें.

ध्यान दें:
- Contact form अभी demo है; messages भेजने के लिए बाद में Formspree/Google Forms/backend जोड़ा जा सकता है.
- Gallery में अपनी photos जोड़ने के लिए HTML/CSS बदला जा सकता है.
